# Astronymic

Type a word and watch it being drawn as a constellation of stars.

Each letter is a segment between two stars, with small stars above or below it depending on the alphabet. The word is read starting from the circled star, going clockwise.

## Credits

The constellation language is not mine. It was created by [@the_alchemy_book](https://www.instagram.com/the_alchemy_book/).

This website only generates images based on the system they created. I'm not trying to claim the idea as my own: I really liked it and wanted to expand on it with a tool that can draw any word. If you enjoy it, go check out their original work.

## Development

```bash
npm install
npm run dev        # development server
npm run build      # production build
npm run test       # tests
npm run typecheck  # type checking
```

Stack: Vite + TypeScript, no UI framework and no runtime dependencies.
